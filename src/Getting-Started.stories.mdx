# landrik Design System React Components

landrik-ui is a set of React component libraries i created, it consists of working code, design tools and resources, and human interface guidelines. It is a project based on my experience as UI designer and developer, following the principles of accessibility, usability, and maintainability.

## Requirement

- Node.js 20.9.0 ([installation with nvm](https://github.com/creationix/nvm#usage))
- Npm 10.8.2+

## Installation

```shell
npm i @landrik-ui
```

## Example

```bash
@import { Button } from '@landrik/ui'

```

## Quick Start

```tsx
import { ThemeProvider, Button, TextField } from '@landrik/ui';

function App() {
  return (
    <ThemeProvider>
      <Button variant="primary">Click me</Button>
      <TextField label="Email" type="email" />
    </ThemeProvider>
  );
}
```
