# landrik Design System React Components

landrik-ui is a set of React component libraries i created for KubeSphere console.

## Requirement

- Node.js 20.9.0 ([installation with nvm](https://github.com/creationix/nvm#usage))
- Yarn 1.22.4+

## Installation

```shell
npm i @landrik-ui
```

## Example

```bash
@import { Button } from '@landrik/ui'

```

## Quick Start

```tsx
import { ThemeProvider, Button, TextField } from '@landrik/ui';

function App() {
  return (
    <ThemeProvider>
      <Button variant="primary">Click me</Button>
      <TextField label="Email" type="email" />
    </ThemeProvider>
  );
}
```

## Running Storybook

npm run storybook
